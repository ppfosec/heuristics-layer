# Private judgment repository

Keep three kinds of material separate:

1. Session packets preserve the case, evidence, interpretation, and evaluation.
2. Proposed library changes remain candidates waiting for practitioner review.
3. `JUDGMENT_LIBRARY.md` contains only practitioner-approved heuristics.

## Recommended layout

```text
Heuristics Layer/
  library/
    JUDGMENT_LIBRARY.md
  sessions/
    2026/
  proposals/
    2026/
  archive/
```

Use a private Google Drive folder or private local folder as the source of record. Do not treat Project knowledge as an automatically synchronized database.

After each interview:

1. Save the session packet and proposed-changes file.
2. Review each candidate against its excerpts, counterexample, uncertainty, and reversal conditions.
3. Approve, revise, merge, split, probe, or reject it.
4. Start with the supplied empty `JUDGMENT_LIBRARY.md` and merge only approved wording into it.
5. Replace any stale Project copy with the reviewed source-of-record library.

Do not silently promote proposals. Do not place private interviews or the judgment library in the public product repository.
