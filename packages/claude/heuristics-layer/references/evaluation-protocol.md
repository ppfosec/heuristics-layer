# Evaluation protocol

Perform semantic editorial judgment. Do not use keyword counts, field-completion checks, or a total score as a substitute for interpretation.

1. Reconstruct the decision, including facts, uncertainty, actors, incentives, authority, resistance, consequences, reversibility, time pressure, and question sequence.
2. Propose the smallest set of reusable candidates supported by the interview. Keep case facts separate.
3. Challenge each candidate with a counterexample, changed condition, alternative explanation, missing stakeholder perspective, and disconfirming evidence.
4. Revise, narrow, split, defer, or reject weak candidates.
5. Assess each candidate as `strong`, `partial`, `unsupported`, or `contradicted` for transcript fidelity, causal depth, human-system coverage, trade-off quality, boundedness, actionability, transferability, and provenance. Explain each assessment without calculating a total.
6. Recommend `approve`, `revise`, `probe`, `merge`, `split`, or `reject`. Only the expert can mark a heuristic approved.

Expose evidence, interpretation, challenges, uncertainty, and proposed decisions. Do not expose or request hidden chain-of-thought.
