# Publish publicly

Use this optional phase only after a heuristic has been published privately. Read `core/PUBLISH_PUBLICLY.md` when available and follow the same contract.

Private approval does not authorize public contribution. Prepare sanitized public wording, explain what was removed, compare it with the public library, run a privacy check, and ask for separate approval of the exact public version.

After approval, assign the next `HL-P-####` identifier, update only public-safe repository files, validate, commit intentionally, push, and open a pull request. Record the resulting public identifier and URL in the private repository. Never ask the practitioner to edit or operate Git.
