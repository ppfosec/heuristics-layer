# Optional public contribution

Publishing here makes a heuristic authoritative in the private library. It does not publish it on GitHub.

After a private publication, ChatGPT or Claude may ask whether the practitioner wants to prepare a sanitized public contribution. If yes, read the product's `PUBLISH_PUBLICLY.md` protocol, prepare exact public wording, remove private evidence and identifiers, and obtain separate approval before any GitHub write.

The application performs the public-library comparison, identifier assignment, privacy scan, file creation, Git commit, push, pull request, and private status update. The practitioner does not move or reconcile files.

If the application cannot access the public repository and GitHub, leave the contribution pending. Never describe a local draft as publicly published.
