# Thesis

General-purpose models already know a great deal about controls, evidence, authentication, risk, and audit. More documents do not automatically give them the judgment an experienced practitioner uses when a vendor answer is technically true and still unhelpful.

That judgment appears in distinctions:

- A certification can be strong evidence and irrelevant to the question being asked.
- A shared account can weaken accountability, while a shared target identity behind a properly operated PAM broker may preserve it.
- A control gap can be real and immaterial.
- A product can support a compensating control without proving that the capability is configured or operating.

The Heuristics Layer tests whether structured interviews can make those distinctions explicit, reviewable, versioned, retrievable, and useful to a model at inference time.

The contribution is not the invention of heuristics or expert systems. It is a practical pipeline for eliciting tacit judgment, challenging the first abstraction, requiring expert approval, and measuring what changes when that approved judgment is retrieved.
