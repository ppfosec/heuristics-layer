# Heuristics Layer v0.3.0

The interview was never the whole product. The missing step was turning a good conversation into an approved judgment library without making the practitioner reconcile Markdown, invent identifiers, move evidence, and update six ledgers by hand.

Version 0.3 closes that loop. ChatGPT or Claude can now ingest interview outputs, compare candidates across sessions, challenge weak or overfitted claims, ask one substantive approval question at a time, and publish the approved result into a private source of record. The application handles the library, publication log, unresolved queue, intake manifest, dated evidence, versions, identifiers, and repository state.

The working model stays simple:

- the public Heuristics Layer repository contains the framework and downloads;
- a separate private folder contains the practitioner's library and interview evidence;
- mobile or laptop voice runs the interview;
- ChatGPT Work or Claude Cowork performs the local publication transaction on desktop;
- accounts without local folder access can receive one complete replacement repository ZIP.

Private publication does not silently become public publication. A practitioner can separately approve a sanitized public contribution, but the private evidence and identifiers stay out of GitHub.

The release includes ChatGPT and Claude ZIPs, the same optional portable Agent Skill in both packages, an empty private-repository template, synthetic examples, a full validator, and documented platform limitations. Real ChatGPT and Claude voice interviews produced the source material used for acceptance. A live private-repository pass normalized seven candidates, published nothing before approval, and completed one approved transaction while leaving six candidates visibly blocked.

Download the ZIP for your platform, prepare one chat on desktop, open that same chat on mobile, and start talking. The dishes remain optional.
