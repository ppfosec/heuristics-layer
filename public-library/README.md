# Public heuristic library

This directory contains practitioner-approved, sanitized GRC heuristics contributed through Heuristics Layer. These are reusable judgment records, not universal rules, vendor scores, or autonomous approval logic.

Every public entry requires:

- an immutable `HL-P-####` identifier;
- version and publication status;
- use conditions and observable cues;
- causal and organizational reasoning;
- an action a practitioner can take;
- adaptation for stakeholders and incentives;
- boundaries, reversal conditions, and a counterexample;
- explicit uncertainty;
- non-identifying provenance;
- separate approval of the exact public wording.

Private identifiers, interview evidence, source filenames, company details, and local paths are prohibited. Contributions should arrive through a reviewed pull request with passing validation.
